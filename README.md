# Solar AI 1.0.0 — Windows

Ce dépôt contient uniquement les fichiers de téléchargement de l’installateur Windows. Le code source de Solar n’y est pas inclus.

## Installation
1. Téléchargez tous les fichiers de la release et placez-les dans le même dossier.
2. Lancez `Solar AI Setup 1.0.0.exe`.
3. Le modèle de conversation se télécharge après l’installation.

[Voir la release v1.0.0](https://github.com/chrisjaspard66-web/solar-ai-installer/releases/tag/v1.0.0)
